rawraft is a distributed key-value store built in Rust using the Raft consensus algorithm, implemented from scratch.

- [x] Workspace and crate skeleton
- [x] KV engine, session dedup, snapshot/restore
- [ ] Raft core types and in-memory log storage
- [ ] Leader election
- [ ] Deterministic cluster simulator
- [ ] Log replication and commit
- [ ] Durable storage (WAL, crash recovery)
- [ ] Networking and node runtime
- [ ] Server and CLI client
- [ ] Linearizable reads
- [ ] Snapshots and log compaction
- [ ] Linearizability and chaos testing
